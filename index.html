三合一

Claude Code？Codex？DeepSeek？一个工作台全都要

别的客户端挑内核，Little Claude 直接把三大 Agent Harness 收进同一个桌面—— Claude Code、Codex、DeepSeek 统一接入，聊天记录还能一键互转。 任何兼容 OpenAI / Anthropic 格式的模型端点也能像 CCSwitch 一样直接挂上： 写文案用小模型，改代码切大模型，想换随时换，跟换输入法一样顺手。

权限安全

它想动你的文件？先问过你

让 AI 碰你的电脑，谁都怕它乱来。所以它每一步都会先弹出一张卡片问你： 这个文件能读吗？这条命令能跑吗？你点头它才动。它还会先把计划列成审查单给你过目， 改到你满意再执行——在你的眼皮子底下干活，跑不远的。

流式可视

它不是"啪"地丢个答案就完事

回答是一行一行流出来的，你能看着它推理、改主意、甚至发现自己说错了往回找补。 聊着聊着跑偏了？Rewind 按轮次回退，连当时的文件状态一起恢复， 回退完它还记得之前聊过什么——每一步都留了后悔药。

多模态

刷到个视频教程，三分钟帮你啃完

B 站、YouTube 的链接丢进来，自动下载、语音转文字、逐帧看画面， 几分钟吐给你一份要点总结。还有面试模式：题目截个图丢过去，它帮你识别题目、理清思路， 面试前临时抱佛脚就靠它了。

会话管理

上周聊的啥？搜一下就回到现场

历史对话全部全文可搜，按日期、按项目筛一下，点进去就是当时的聊天现场。 换工具也不怕搬家——Claude 和 Codex 的聊天记录一键互转，想导出 Markdown、JSON 都随你。 会话数据全部存在本地，不绑任何云账号。

零配置

不用配环境，下载完就能开始用

受够了"先装个 Python，再配个环境变量"？安装向导全自动搞定， Windows 单文件便携版免安装、免管理员，U 盘一插就能跑。 出新版本应用内一键热更，GitHub 卡了自动走 CDN 和镜像——不用到处找安装包。

桌面陪伴

它还是你的桌面伙伴

桌宠会在旁边陪着你：思考时冒点点、跑工具时扫描线、任务完成撒彩带、失败掉泪滴， 任务结果还会弹系统通知，切走也不会错过。喜欢氛围感的，还能设动态壁纸—— 桌面与 AI 共生，帧率不够它自己降级，绝不拖慢你的界面。
